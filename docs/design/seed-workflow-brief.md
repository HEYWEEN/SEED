# SEED workflow

The figure shows how the SEED Chrome extension starts from a real GitHub Issue and offers two ways to generate a summary. The case is Kubernetes Issue #135900.

Read down from the extension to the Issue, then follow either arrow to the right. The upper path shows SESAME extracting evaluations before DeepSeek summarizes them. The lower path shows DeepSeek summarizing the title, body, and comments loaded on the page.

The Chrome extension and GitHub Issue screenshots use the supplied captures. The evaluation preview shows the statistics and first evaluation card. The summary previews show the result sections of the two supplied captures. The flowchart labels use Comic Sans MS. The canvas is transparent. The SVG contains editable labels, boxes, and arrows, with the original interface excerpts embedded as raster images.
